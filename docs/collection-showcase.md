# Collection showcase template

Three toggle buttons select Lunarie, BooBoi or Jaygyii. Exactly one collection is mounted at a time, in one consistent template: original character and illustrated universe; figurine, miniature and acrylic charm; product views, packaging and series. Toggling replaces all images, labels, motifs and evidence together without navigating, stacking examples or calling AI generation.

Desktop has three product columns. Mobile retains the three-column overview with shorter captions and tap-to-enlarge concept previews; the character controls wrap naturally. Prototype and provenance details start collapsed, reset on character change and occupy space only when requested. Lunarie alone exposes its existing paper proof; the other examples never borrow that prototype claim.

Lunarie's figure remains an earlier verified ARTOY output. BooBoi and Jaygyii are curated built-in image-generation examples using each original and its approved static figurine. Each new 1536x1024 WebP sheet contains six 512px panels in matching order. All three are reviewed for visual identity; none is a manufacturing specification. The page explicitly retains the pending live workflow status and absence of fabricated physical samples.

Verification: React StrictMode DOM fixture selects all three examples and back again; asserts one active panel, six matching sheet viewports, selected-button semantics, valid ARIA references, scoped PDF link, collapsed evidence zero fetch calls, and the packaging inspection dialog opening on the correct panel and closing back to the collection. Asset dimensions and visual identity reviewed. TypeScript, changed-file lint, build and whitespace checks pass.
