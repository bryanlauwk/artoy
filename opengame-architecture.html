🎮 Game Skill

📐 Template Skill
  • Classifies game type from GDD
  • Selects engine template (canvas / Phaser / three.js / UI)
  • Copies & configures project skeleton
  • Grows a library of skeletons from past runs
  • Ensures stable cross-file architecture
🐛 Debug Skill
  • Runs game in sandboxed headless browser
  • Captures console errors & broken interactions
  • Maintains living protocol of verified fixes
  • Patches integration errors vs. syntax bugs
  • Iterates until game is fully playable

🛡️ Sandbox Execution Modes

None (default)
Runs directly on host. Fast, no containers needed. Shell commands still gated by approval mode.
Docker
GEMINI_SANDBOX=docker — game runs in ghcr.io/leigest519/opengame:0.6.0 container.
Podman
GEMINI_SANDBOX=podman — rootless container alternative for CI or locked-down environments.
macOS Sandbox
Apple .sb profiles: permissive-open, permissive-closed, restrictive variants for fine-grained control.

🚀 Quick Start

# Set your LLM API key
export OPENAI_API_KEY="sk-..."
export OPENAI_MODEL="gpt-4o"

# (Optional) wire up asset providers
export OPENGAME_IMAGE_PROVIDER=tongyi
export OPENGAME_IMAGE_API_KEY="sk-..."

# Create a game folder and run the agent
mkdir -p agent-test/games/my-game && cd agent-test/games/my-game
opengame -p "Build a Snake clone with WASD controls and a dark neon theme." --yolo

# Open the output in your browser
open index.html
